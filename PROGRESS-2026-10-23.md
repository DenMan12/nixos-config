## Проблемы

### VirtualBox display issues

**Симптом:** Сильное мерцание экрана в GNOME Live, VM зависла во время сборки

**Причина:** VBoxVGA + 3D acceleration плохо работают с Wayland/GNOME

**Решения:**
1. **Попробовать другой Graphics Controller:**
   - VM Settings → Display → Graphics Controller
   - Варианты: VBoxSVGA, VMSVGA (вместо VBoxVGA)
2. **Отключить 3D Acceleration** (но тогда Niri не запустится нормально)
3. **Использовать QEMU/KVM вместо VirtualBox:**
   - Лучше поддержка Wayland через virtio-gpu
   - Команда для запуска с 3D:
     ```bash
     qemu-system-x86_64 \
       -m 4G -smp 2 \
       -enable-kvm \
       -cdrom ~/Downloads/nixos-gnome-24.05.iso \
       -drive file=nixos-test.qcow2,format=qcow2 \
       -vga virtio -display gtk,gl=on
     ```
4. **Использовать NixOS minimal ISO** (без GNOME) — меньше нагрузка на display

## Команды для продолжения

### На хосте (Arch)

```bash
cd ~/MyGitDir/nixos-config

# Поправить конфиг
nvim configuration.nix

# Закоммитить
git add -A
git commit -m "Fix: описание изменений"
git push
```

### В VM

```bash
cd nixos-config

# Обновить репо
git pull

# Собрать систему (без установки)
sudo nixos-rebuild build --flake .#nixos

# Если сборка успешна — установить на диск
sudo nixos-install --flake .#nixos
```

### QEMU/KVM (альтернатива VirtualBox)

```bash
# Создать диск
qemu-img create -f qcow2 nixos-test.qcow2 20G

# Запустить с ISO
qemu-system-x86_64 \
  -m 4G -smp 2 \
  -enable-kvm \
  -cdrom ~/Downloads/nixos-gnome-24.05.iso \
  -drive file=nixos-test.qcow2,format=qcow2 \
  -vga virtio -display gtk,gl=on
```
